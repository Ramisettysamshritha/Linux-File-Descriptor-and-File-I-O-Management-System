## Project Description

This project is a Linux terminal-based file management system developed in C using Linux system calls. It performs file operations through file descriptors.

## Features
- Create File
- Write File
- Read File
- Append File
- Copy File

## Linux APIs Used
- open()
- read()
- write()
- lseek()
- close()

## Compile

```bash
gcc file_manager.c
```

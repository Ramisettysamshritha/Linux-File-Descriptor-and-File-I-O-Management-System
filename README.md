## Project Description

This project is a Linux terminal-based file management system developed in C using Linux system calls. It performs basic file operations using file descriptors.

## Features

1. Create File
2. Write File
3. Read File
4. Append File
5. Copy File

## Linux APIs Used

- open()
- read()
- write()
- lseek()
- close()

## Compile

```bash
gcc file_manager.c
```
